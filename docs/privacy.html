Privacy Policy for HappySubs

Last updated: July 5, 2026

HappySubs is an unofficial browser extension that adds a second subtitle overlay while you watch YouTube videos. This extension is not affiliated with, endorsed by, or sponsored by YouTube or Google.

Data We Store

The extension stores your settings in Chrome extension storage, such as selected subtitle language, subtitle style, translation provider, and optional API keys that you enter for third-party translation services. This data is stored in your browser through Chrome storage and is not sent to any server operated by the extension developer.

Data Sent to Third Parties

When you use translation features, subtitle text may be sent directly from your browser to the translation provider you choose, such as Google Translate, OpenAI, Anthropic Claude, Google Gemini, or DeepSeek. If you enter an API key for one of these services, that key is used only to call the selected provider from your browser.

Data We Do Not Collect

The extension developer does not operate a backend server for this extension, does not collect your browsing history, does not sell user data, and does not share user data with advertisers or data brokers.

Permissions

The extension requests access to YouTube pages so it can display the subtitle overlay and process available subtitle text while you watch videos. It requests access to translation provider domains only so it can send subtitle text for translation when you use those providers.

Deleting Your Data

You can delete extension data by removing the extension from Chrome or clearing the extension's stored data in your browser. You can also remove saved API keys from the extension popup.

Contact

For questions or requests, please open an issue at github.com/huanshuowang/youtube-dual-subtitles.
