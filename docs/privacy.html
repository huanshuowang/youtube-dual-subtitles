Privacy Policy for HappySubs

Last updated: August 30, 2026

HappySubs is an unofficial browser extension that adds a second subtitle overlay while you watch YouTube, Vimeo and Bilibili videos, and can optionally transcribe videos that have no subtitles at all. This extension is not affiliated with, endorsed by, or sponsored by YouTube, Google, Vimeo or Bilibili.

Data We Store

The extension stores your settings in Chrome extension storage, such as selected subtitle language, subtitle style, translation provider, and optional API keys that you enter for third-party translation services. This data is stored in your browser through Chrome storage and is not sent to any server operated by the extension developer.

Data Sent to Third Parties

When you use translation features, subtitle text may be sent directly from your browser to the translation provider you choose, such as Google Translate, OpenAI, Anthropic Claude, Google Gemini, or DeepSeek. If you enter an API key for one of these services, that key is used only to call the selected provider from your browser.

Live Transcription and Audio

Live transcription is an optional feature that is off unless you install a separate local program and switch it on in the extension. While it is running, the extension reads the audio of the video you are watching and sends it over a loopback connection (ws://127.0.0.1:8765) to that program, which runs on your own computer and returns recognised text.

The audio does not leave your computer. It is not uploaded anywhere, not recorded to disk by the extension, and not sent to the extension developer or to any third party. Nothing is captured while the feature is switched off, and the extension never accesses your microphone — only the audio of the video element on the page you are watching.

The recognised text is then translated the same way subtitle text is: sent to whichever translation provider you have chosen.

Data We Do Not Collect

The extension developer does not operate a backend server for this extension, does not collect your browsing history, does not sell user data, and does not share user data with advertisers or data brokers.

Permissions

Every host the extension asks for corresponds to something it actually does:

  • www.youtube.com, vimeo.com, player.vimeo.com, www.bilibili.com — the pages the extension runs on, to read the video's subtitles and draw the overlay.
  • captions.vimeo.com, api.bilibili.com — where those two sites publish their subtitle files, which the extension fetches to translate.
  • translate.googleapis.com, api.anthropic.com, api.openai.com, generativelanguage.googleapis.com, api.deepseek.com — the translation providers, contacted only for the one you have selected.

Live transcription needs no host permission: it talks to a program on your own machine over a loopback address.

Deleting Your Data

You can delete extension data by removing the extension from Chrome or clearing the extension's stored data in your browser. You can also remove saved API keys from the extension popup.
