三步上手

已上架 Chrome 应用商店，点一下即可安装。

1

添加到 Chrome

打开 Chrome 应用商店页面， 点 添加到 Chrome，确认安装即可。

2

打开视频

YouTube 上点右下角的 CC 按钮开启原生字幕（你想学的那种语言），扩展要靠它拿字幕。Vimeo 和 B站 上扩展直接读字幕轨，字幕开不开都行。完全没有字幕的视频，用实时听译。

3

选第二语言

点浏览器右上角的扩展图标，选第二语言即可。翻译会自动叠加到原生字幕上方。

想自己装？完整源码在 GitHub 上，clone 下来后在 chrome://extensions 打开开发者模式，点"加载已解压的扩展"选这个文件夹即可。

实时听译

为完全没有字幕轨的视频创造字幕。可选功能，目前支持中英双语。

安装本地识别服务

需要系统装有 python3。一条命令，不用 clone 仓库——脚本会在当前位置建一个 happysubs-server 文件夹，装好 Python 环境，并从 sherpa-onnx 项目自己的 release 下载模型（约 500MB 压缩包，解压后保留 193MB）。

curl -fsSL https://raw.githubusercontent.com/huanshuowang/happysubs/main/setup.sh | bash

装好后启动它，看视频期间让它一直开着：

cd happysubs-server && .venv/bin/python server.py

看到 监听 ws://127.0.0.1:8765 就绪。然后在插件弹窗切到「实时听译」标签，点开启。

几点注意：先点一下视频播放，浏览器要求有用户交互才允许处理音频。服务端一次只服务一个页面，同时开多个标签页会互相干扰。端口被占用时执行 lsof -ti:8765 | xargs kill 再重启。模型和 Python 环境都在这个文件夹里，换机器重跑一次上面那条命令即可。已经 clone 了整个仓库的话，在仓库根目录跑 ./setup.sh 效果一样。

常见问题

为什么 YouTube 必须开 CC，Vimeo 却不用？

YouTube 上扩展是靠拦截播放器自己去拿字幕的请求，而 YouTube 只在你开 CC 的时候才发这个请求。Vimeo 则是把字幕轨当普通文件放出来，扩展可以自己去读，所以不需要先开任何东西。如果你只想看译文，在插件弹窗里打开 仅显示翻译字幕，关着 CC 也会单独显示第二语言。

B 站需要装什么吗？

不需要。B 站的字幕轨跟其他平台一样直接读取。本地服务只跟实时听译有关，而实时听译只用于完全没有字幕轨的视频。

B 站上提示这个视频没有字幕，是真的吗？

多半是。B 站只对**登录用户**返回字幕列表，所以先确认你登录了。如果已经登录、扩展仍然找不到，那就是真的没有——这正是实时听译存在的理由。

如果视频没有字幕怎么办？

YouTube 和 Vimeo 上大部分视频有自动生成字幕。B 站上大部分**没有**，这正是实时听译的用武之地——它直接听音频，自己把字幕写出来。

翻译准确吗？

默认优先使用视频自带字幕或 Google 免费翻译。如果你需要更高质量，可以手动为当前视频启用 Claude / OpenAI / Gemini / DeepSeek。

会上传我的数据吗？

扩展代码完全开源可审。它只读取当前视频字幕，并只把字幕文本发送到你选择的翻译源。付费 API 只有在明确确认后才会调用。
