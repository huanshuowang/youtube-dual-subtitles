四步安装

目前需要用 Chrome 的开发者模式手动加载。

1

下载扩展

点击顶部 下载扩展 按钮，得到一个 .zip 文件。解压到你喜欢的位置（比如"文档"文件夹）。

2

打开 Chrome 扩展页面

地址栏输入 chrome://extensions 回车，右上角打开 开发者模式（Developer mode）。

3

加载已解压的扩展

点左上角 加载已解压的扩展（Load unpacked），选择刚解压出来的 youtube-dual-subtitles-main 文件夹。

4

打开 YouTube 视频

先点视频右下角的 CC 按钮开原生字幕（你想学的那种语言），然后点浏览器右上角的扩展图标， 选第二语言即可。中文字幕会自动叠加到英文字幕上方。

常见问题

为什么必须打开 YouTube 原生 CC 字幕？

因为扩展需要拦截 YouTube 播放器自己去拿字幕的请求。YouTube 只在你开 CC 的时候才发这个请求，我们才能拿到完整的字幕数据来翻译。

如果视频没有字幕怎么办？

YouTube 上大部分视频有自动生成（ASR）字幕。真的一点都没有的视频，扩展没法凭空生成字幕，这种情况暂时无解。

翻译准确吗？

默认优先使用视频自带字幕或 Google 免费翻译。如果你需要更高质量，可以手动为当前视频启用 Claude / OpenAI / Gemini / DeepSeek。

会上传我的数据吗？

扩展代码完全开源可审。它只读取当前视频字幕，并只把字幕文本发送到你选择的翻译源。付费 API 只有在明确确认后才会调用。
